# Portfolio

Kishor Rana Chhetri's personal portfolio site, which presents Kishor's engineering work and background to recruiters and hiring managers.

## Language

### People

**Visitor**:
A recruiter or hiring manager reading the site; the person every page is written for.
_Avoid_: User, reader, client

**Client**:
An organisation Kishor delivered work for through an employer.
_Avoid_: Customer, Visitor

### Work

**Project**:
One piece of delivered work, shown on the Work page.
_Avoid_: Case study, portfolio item, piece

**Client work**:
A Project delivered for a Client; anonymised by default and illustrated with an architecture diagram, never client screenshots.
_Avoid_: Professional project, commercial work

**Personal work**:
A Project Kishor built independently, with code and a demo link where available.
_Avoid_: Side project, hobby project

**Placeholder project**:
An interim Project drawn from the résumé, shown only until Kishor supplies a real one to replace it.
_Avoid_: Filler, dummy project, sample project

**Draft**:
A Project that exists in the content but is hidden from the site until it is ready.
_Avoid_: Unpublished, hidden, WIP

### Background

**Role**:
A position held at an employer, with title, employer and dates.
_Avoid_: Job, position

**Earlier roles**:
The pre-2021 IT support and operations Roles, shown condensed to a single line rather than in full.
_Avoid_: Old jobs, previous experience

**Certification**:
A credential issued by a vendor (Microsoft, AWS, CompTIA), with a year and a verify link where one exists.
_Avoid_: Cert, badge, credential

**Featured certification**:
One of the four Certifications given prominence over the rest.

### Pages

**Work page**:
The home page: name, headline, call to action, and the list of Projects.
_Avoid_: Home, landing page

**Info page**:
The page holding Experience, Education, Certifications and Skills.
_Avoid_: About page, résumé page
